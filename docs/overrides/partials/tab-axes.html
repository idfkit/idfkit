{#- Tab axis registry and pre-paint reconciliation (FR-053, FR-054). Two things happen here, both before the browser paints: 1. `window.__idfkitTabAxes` declares every tab axis the site uses. An axis is a set of tab labels that mean the same choice wherever they appear ("Python" / "TypeScript" for the language axis), the query parameter that carries it, and the value spelling used in the address. `docs/javascripts/tab-sync.js` reads the same object, so an axis is declared once. Labels must match the Markdown (`=== "Python"`) character for character. 2. A URL such as `?language=typescript` is promoted into `__tabs`, the localStorage key Material for MkDocs (9.7.x) uses to remember tab choices. Material's own restore script, which runs later in the body and again after every instant navigation, then activates the right tabs itself, before the first paint and without a visible flip. That makes the URL the source of truth on arrival and leaves the stored preference as the fallback when the address carries no parameter, without a second mechanism fighting Material's. `__md_get` / `__md_set` come from `partials/javascripts/base.html`, which base.html includes ahead of `extrahead`, so they are defined by the time this runs. -#}
